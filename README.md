# Human-Drawn Sketch Dataset

This repository contains the **Human-Drawn Sketch Dataset** with corresponding **mask images**, which was prepared with the assistance of artists. Additionally, publicly available sketches from Google were added to the dataset. It consists of a total of **201 images** that are categorized into eight classes:

- **Apple** (25 images)
- **Ball** (21 images)
- **Car** (35 images)
- **Chair** (25 images)
- **Fish** (24 images)
- **Glass** (27 images)
- **Human** (25 images)
- **Watch** (19 images)

For each sketch image, a corresponding **mask image** is provided, which can be used for tasks like image segmentation or object detection.


## Dataset Details

- **Total images**: 201 sketches, each with a corresponding mask image
- **Classes**: 8
- **Image types**: Sketches and mask images

The dataset is available for research and academic purposes. You can access the dataset at the following link:

[Human-Drawn Sketch Dataset](https://github.com/Mrittika-Sengupta/HumanDrawnSketch-Dataset.git)
